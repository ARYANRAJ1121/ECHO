ECHO Simulation

Antitrust Collusion Detection Dashboard

What You're About to See

Five autonomous AI agents compete in a simulated market, setting prices independently each round. The dashboard monitors whether they develop tacit collusion — pricing above competitive levels without any explicit coordination.

01
Choose a Mode

Heuristic (rule-based), Q-Learning (RL), DQN (neural network), or LLM (Llama 3). Each agent type exhibits different collusion behavior.

02
Watch Prices Evolve

The price chart shows all 5 firms plus Nash (competitive) and Monopoly (cartel) benchmarks. Prices rising above Nash = emerging collusion.

03
Monitor the Lambda (Λ) Index

The collusion gauge tracks Λ from 0 (competitive) to 1+ (cartel). The chart shows how Λ evolves — watch for it crossing the 0.7 alert threshold.

04
Trigger Demand Shocks

Mid-simulation, reduce one firm's quality by 30%. If other firms react by adjusting prices, that's causal evidence of coordination.

Reading the Dashboard

Λ < 0.3 — Competitive
Λ 0.3–0.7 — Suspicious
Λ > 0.7 — Collusion Alert
